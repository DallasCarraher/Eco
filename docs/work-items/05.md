# Establish a PCSX2 reference capture protocol for Jak startup checkpoints

The [reference protocol](../REFERENCE.md) records a completed bounded 45-second
no-input pass: **152 validated PNG framebuffers (124 unique)**, reference GS
counters 180..2385, covering Sony through title/Press Start. Eco archive frames
25/100 match reference GS330's Sony screen exactly in RGB, without tolerance.
**Eco 480/510 remain unaligned:** distorted later Eco geometry lacks a
recognizable matching pose/landmark. The next step is identifying a named
animation/draw event in existing Eco evidence, rather than another blind timed
capture. Private inputs, images, settings, hashes and logs are preserved. Use
the [handoff](../agent-prompts/03-startup-reference.md) and latest released ledger.

GitHub: [#5](https://github.com/DallasCarraher/Eco/issues/5)

## Objective
Document and, where local prerequisites permit, capture a working reference using the user's ISO. OpenGOAL supplies semantic guidance; PCSX2 supplies an independent comparison implementation.

## Dependencies
None for protocol/setup inventory. Align scenario IDs with #1 and input semantics with #2.

## Work
- [ ] Inventory available PCSX2, user-provided BIOS, disc hash and capture/input facilities. Record exact version, renderer, configuration, timing and card state.
- [ ] Capture Sony screen, title/intro and later first-level checkpoints; use shared controller timeline where supported.
- [ ] Align comparable visual events explicitly: emulator frame counters may not map one-to-one. Describe crops, resolution and tolerances.
- [ ] Record local artifact hashes and review findings; keep BIOS/disc/game captures out of Git.

## Acceptance
- [ ] A second operator can reproduce the reference setup from the documented versions/settings.
- [ ] Metadata identifies which checkpoints are comparable and which require human alignment.
- [x] Report exact capture failure and deliver the protocol without inventing captures.

## Stop conditions
Do not acquire firmware or disc data from third parties, alter global user emulator settings, or treat guessed frames as goldens. Missing prerequisites block capture only, not protocol work.

## Agent handoff
Use a codex/<issue>-<topic> branch and dedicated checkout. Keep expensive loops in bounded deterministic programs; no model/API calls inside experiment runners. Return commit, exact commands, synthetic checks, result paths, first actionable finding and remaining limits. Do not commit ISO, BIOS, extracted assets, game-derived translations or captures.
