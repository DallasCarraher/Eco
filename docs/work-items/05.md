# Establish a PCSX2 reference capture protocol for Jak startup checkpoints

The [reference protocol](../REFERENCE.md) now records **14 independent early
startup PNG captures** from verified PCSX2 2.8.2 and the supplied BIOS. They show
the Sony presents screen at reference GS counters 180..330; **Eco frame 510 is
still unaligned**. The no-input continuation stopped after 8.272 s because its
early-output monitor searched BMP only. A format-aware helper and five passing
synthetic tests now cover PNG/BMP and partial-file handling. No game restart was
attempted. All images/settings/hashes stay private. Use the updated
[handoff](../agent-prompts/03-startup-reference.md) and latest released ledger
before any separately authorized continuation. Prior inventories and the failed
first setup cycle remain historical evidence.

GitHub: [#5](https://github.com/DallasCarraher/Eco/issues/5)

Document and, where local prerequisites permit, capture a working reference using the user's ISO. OpenGOAL supplies semantic guidance; PCSX2 supplies an independent comparison implementation.

## Acceptance
- [ ] A second operator can reproduce the reference setup from the documented versions/settings.

## Stop conditions
Do not acquire firmware or disc data from third parties, alter global user emulator settings, or treat guessed frames as goldens. Missing prerequisites block capture only, not protocol work.

Return commit, exact commands, synthetic checks, result paths, first actionable finding and remaining limits. Do not commit ISO, BIOS, extracted assets, game-derived translations or captures.
