# Extend GOAL coverage from startup toward Sandover with relocation regressions

GitHub: [#6](https://github.com/DallasCarraher/Eco/issues/6)

## Objective
Investigate the observed browser missing entry 0x0068AA28 (RA 0x006896BC) on the baseline route, then classify subsequent misses within a bounded exploration budget.

## Work
- [ ] Reproduce the miss against the recorded baseline/input route; address alone is not a stable identity after heap changes.
- [ ] Classify absent entry, relocation, page boundary, stale snapshot or opcode mismatch. Record object/program identity where available.
- [ ] Use bounded coverage generation in a dedicated checkout, then freeze/rebuild before measurement. Do not race shared overlays.
- [ ] Prefer general relocation/invalidation fixes with original synthetic tests over unchecked dispatch or ever-broader snapshots.

## Acceptance
- [ ] The targeted route progresses past the reproduced miss with full instruction validation enabled.
- [ ] Regression covers the diagnosed cause, including relocation to two addresses or rewritten code when applicable.
- [ ] Report next uncovered path, generated-code growth and whether a clean local rebuild reproduces progress; frame count alone is not gameplay proof.

## Stop conditions
Cap each exploration at 10 rounds and one hour initially. Stop on identical repeated miss without new evidence, semantic mismatch or unexplained code growth; never disable PS2_WINDOW_FULL to get past a halt.

## Agent handoff
Use a codex/<issue>-<topic> branch and dedicated checkout. Keep expensive loops in bounded deterministic programs; no model/API calls inside experiment runners. Return commit, exact commands, synthetic checks, result paths, first actionable finding and remaining limits. Do not commit ISO, BIOS, extracted assets, game-derived translations or captures.
