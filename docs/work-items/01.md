## Implementation evidence

Runner implementation: `1b1a9d4` on `codex/issue-1-experiment-runner`.
See [the CLI and report semantics](../EXPERIMENTS.md#implemented-cli-and-report-details)
and [unattended launch/resume commands](../OVERNIGHT.md#run-a-frozen-native-experiment).

- All 20 original synthetic subprocess tests pass, including zero-exit halts,
  missing/malformed summaries, orphan children, time/output/disk limits,
  SIGTERM/SIGINT cancellation, shared-resource locks, resume mismatches and
  paths containing spaces.
- `python3 scripts/jak_smoke.py --web --live-template` passed native execution
  and WASM compilation. Browser execution was not part of this validation.
  The compiled original fixture also ran through the harness and was correctly
  classified as `runtime_halted` on its intentional Exit, at frame 0 with no
  display capture.
- The three-case Jak pilot at the clean implementation commit reached the
  explicit 600-frame limit in all cases. Apple M4 WebGPU repeats had 20/20
  identical capture hashes and identical runtime outcomes. The software case
  had all 20 captures. No case had missing captures or a missing-code halt.
- GPU/software captures first differed at frame 210: 35,392 differing pixels
  across 20 paired captures, maximum channel delta 3. These observations do
  not identify the correct renderer. Software repeatability is unknown from
  this single software case; visual correctness and gameplay remain unverified.
- The initial pilot took approximately 125 seconds. Hash-validated resume then
  retained exactly three case results and launched no additional cases.
  The full 24-case matrix was not launched.
