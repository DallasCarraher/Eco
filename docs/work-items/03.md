# Localize startup geometry corruption with software and WebGPU comparisons

GitHub: [#3](https://github.com/DallasCarraher/Eco/issues/3)

## Objective
Run the fixed native GS matrix and identify the earliest actionable graphics divergence. This is a bounded diagnosis, not a promise to fix all rendering.

## Likely files
runtime/src/gs/gs.cpp and relevant GS GPU/shader code; experiment report tooling. Change rendering only after reproducing a specific fault.

## Work
- [ ] Run gpu-compiled, cpu-compiled and gs-mirror with identical input, repeated checkpoints and a frozen binary.
- [ ] Verify actual GPU use; collect PS2_GS_COMPARE metrics and first differing frame.
- [ ] If software and GPU differ, reduce the relevant state/transfer/primitive stream to a small replay. If both are wrong, trace shared DMA/VIF/VU/GS inputs instead.
- [ ] Add an original synthetic regression for any confirmed fix; rerun the targeted case and reference checkpoints.

## Acceptance
- [ ] Report states first divergence, repeats, compared frames and whether both paths are wrong; no unsupported claim of visual correctness.
- [ ] Deliver a replayable failure or a documented eliminated hypothesis with the next trace boundary.
- [ ] Any fix has a regression that fails before it and passes afterward; title/intro visual signoff cites local reference evidence.

## Stop conditions
One four-hour experiment batch maximum before review. Stop on non-repeatability, unavailable backend or exhausted output budget; do not sweep arbitrary flags indefinitely.

## Agent handoff
Use a codex/<issue>-<topic> branch and dedicated checkout. Keep expensive loops in bounded deterministic programs; no model/API calls inside experiment runners. Return commit, exact commands, synthetic checks, result paths, first actionable finding and remaining limits. Do not commit ISO, BIOS, extracted assets, game-derived translations or captures. The local work-item file is docs/work-items/03.md. Issue numbers in dependencies will be linked in the work-item index.
